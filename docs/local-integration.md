# 本地前端连接服务器联调

## 准备

拉取 frontend 分支，进入包含 package.json 的目录。
使用 Node.js 20，首次运行执行：

```bash
npm ci
```

## 启动

```bash
npx cross-env HOST=127.0.0.1 PORT=8003 DEV_API_TARGET=http://47.111.225.144:8001 DEV_LABELING_TARGET=http://47.111.225.144 npm run start:dev
```

- 登录和训练接口连接服务器 8001 环境。
- 新标注接口通过服务器 80 端口转发至标注服务。
- 以终端显示的实际端口为准。
- 使用 VS Code 远程开发时，需要转发该端口。
- 不使用 dev:local 命令进行远端联调，它会覆盖后端地址。

## 验证

打开本地页面并登录。可通过本地端口验证标注服务：

```bash
curl -i http://127.0.0.1:8003/api/labeling/v1/health
```

服务器标注服务必须使用与前端登录相同的身份来源。
本次联调身份来源为服务器本机 http://127.0.0.1:8001。

## 注意

本地页面操作会写入服务器数据，请给测试项目加上人员标识。
账号权限保存在服务器数据库中，不随 Git 代码复制。
开发代理不影响生产 Nginx 配置。
不要提交密码、令牌、私钥或服务器环境配置文件。
