# V1.1 页面结构与 UI 差异清单

分析日期：2026-11-18。设计依据：用户提供的 `TSS-V1.1-Interaction-Design-Updated.docx` 中 21 张图片（首页示意和 20 个业务页面），以及 `TSS-V1.1-Interactive-Preview.html` 的页面、样式和交互脚本。代码基线：本地 frontend 分支 `b41d9a8`。

本清单在修改应用代码前整理。浏览器安全策略拒绝读取本地页面，以下差异来自参考图片/HTML 与代码的静态对比，不能等同于当前页面截图实测。用户确认没有 Figma 链接；因此采用附件设计，不声称已读取 Figma 组件、变量或 Code Connect 映射。

## 页面结构和组件复用

1. 应用外壳：66px 顶栏、207px 深蓝侧栏、浅灰蓝主画布。顶栏放统一品牌、项目上下文和账户；侧栏按工作区/个人管理分组。
2. 页面标题：面包屑、标题、简短用途说明，右侧仅放当前主要操作或规范选择。
3. 业务模块：白色卡片、47px 左右的卡片标题、14px 内容边距、10px 圆角；表格、表单和状态使用已有 Ant Design。
4. 审核模块：页签、四张可点击统计卡、样本列表/授权原图/审核详情三栏。当前样本与批量勾选分开，范围预览使用抽屉。
5. 执行模块：左侧固定范围摘要，右侧发布/AI 参数；运行进度、历史恢复和高级管理单独成区。
6. 成果模块：左侧保存和选择冻结快照，右侧创建导出、查看状态及下载。来源、模型版本、审核版本仍使用服务器实际数据。
7. 专注标注：能耗曲线与结果表单分区；图片标注沿用可信编辑器；保留未保存离开保护、整包提交与只读状态。

## 各页面差异

| 设计页 | 主要差异及调整目标 |
|---|---|
| 01 我的项目 | 当前横向统计和每行多项管理操作过密；增加已加载项目搜索/状态筛选，项目表与选中项目管理分栏，创建操作移至标题区 |
| 02 新建项目与规范 | 表单和标签区间距较大；使用一致的字段、标签、版本说明和操作区，保留真实模板加载与规范冻结规则 |
| 03 图片导入 | 上传、恢复历史、解析状态和样本浏览缺少统一视觉层级；规范分步与独立面板，错误表格保留来源定位 |
| 04 原生 CSV 数据管理 | 设计指向的 NativeDataPreparation 不在当前 checkout；本次不以静态示意页替代真实功能，现有导入页统一风格 |
| 05 能耗导入与错误定位 | 元数据、错误与曲线视觉混杂；沿用真实导入状态，数据/错误清单/授权曲线分区 |
| 06 首次发布 | 参数、预览和确认纵向堆叠；按本轮要求/分包预览分栏，固定范围和最终确认清楚分开 |
| 07 任务广场 | 列表标题和筛选、空状态及领取操作缺少一致层级；表格紧凑、领取确认仍使用现有真实流程 |
| 08 我的任务 | 已提交记录和恢复操作隐藏较深；任务与提交历史使用一致面板，状态标签和只读说明清晰 |
| 09 图片标注 | 编辑区卡片与样本列表尺寸不一致；保持保存/完成/整包提交区分，统一导航、原图与操作栏 |
| 10 能耗标注 | 曲线、定位控件和结果表单全部纵向排列；大屏曲线/结果双栏，小屏单列，模型置信度与人工自评分开 |
| 11 结果审核 | 统计为一段文字；三栏合在一个边框中；列表完整 UUID 过长；无大图入口；改为可筛选统计卡、独立三栏、短文件名/详情、大图预览 |
| 12 固定范围预览 | 页面底部 details 中混合配置和清单；改为显式打开的预览抽屉，配置/冻结清单分区，保留过期和整体回滚提示 |
| 13 再标注 | 缺少独立固定范围卡；范围与发布参数分栏，显示真实样本数量和规范，参考与重开含义明确 |

## 本地实现与检查结果

已完成现有业务页面的实现，以下为提交前的本地检查记录：

- 全局：附件配色、66px 顶栏、207px 深蓝侧栏、紧凑卡片/表格、选中页签、移动导航、键盘焦点和减少动态效果。
- 项目：创建入口移至标题区；增加已加载项目的名称/说明搜索与状态筛选；列表和当前项目管理分栏，状态操作仍由真实项目权限控制。
- 审核：四张服务器统计卡支持筛选；列表、原图、审核详情独立成栏；样本显示短文件名，完整编号保留详情入口；授权原图可放大查看。
- 固定范围：抽屉内配置与冻结清单分栏；支持排除编号和待修正原因；更改范围会使预览失效，审核失败在抽屉内显示，不隐藏在遮罩后。
- 发布/AI：复用固定范围摘要，与任务参数分栏；保留幂等键、预览失效、终态及规范版本约束。
- 成果：快照创建/列表在左，正式导出在右；能耗编辑器将曲线/定位标记与当前样本结果分栏。
- 任务/用户：统一标题与语义状态；修正“我的任务”中仍声称没有提交历史接口的旧说明。

检查结果：365 项 Node 自动测试通过，`npm run tsc`、变更文件 Biome 检查、`npm run lint:governance` 和 `npm run build` 通过。治理检查有 5 条既有信息提示，无错误或警告。新增测试执行真实组件事件，替换网络与 UI 库边界，覆盖统计筛选参数、范围排除和失效、固定范围审核、图片预览状态/Blob 释放，以及项目搜索/管理选择。未向联调服务器执行发布、删除、审核或 AI 等写操作。

截图差异和 Playwright 浏览器端点击/输入/提交/跳转验收仍未完成：本地页面读取被浏览器安全策略拒绝。上述离线测试不代表浏览器视觉验收通过，也不验证实际焦点、Esc、滚动或像素布局。

设计页 04、18 的原生 CSV/多格式导出/项目完成模块不在当前代码基线；第 19 页质检没有已确认 API。这些部分未新建静态示例功能。品牌保留既有 TSS / AI PLATFORM，以沿用统一平台标识。

## 手动页面验收

提交前已同步远端 frontend 的工作流更新（基线 2c18b11），新增页面保持原功能，并补齐原生编辑器的授权二进制读取、精简项目导航上下文和专注模式兼容。设计差异表中的“基线缺少模块”描述对应最初 b41d9a8 的静态分析，不表示同步后的远端仍缺少这些文件。同步后的平台测试与构建结果以本次 PR 记录为准。

入口：`http://127.0.0.1:8001/#/labeling`。请使用当前账号及项目检查：

1. 项目页：搜索、状态筛选、切换项目管理；品牌返回平台选择；项目内才出现结果/成果入口。
2. 结果页：点击统计卡、筛选来源、选择当前行与勾选批量范围；查看文件名、答案与审核版本；打开原图并按 Esc 关闭。
3. 范围预览：打开抽屉，核对配置/清单；改变排除项后原预览不可执行；待修正原因必填。
4. 发布/AI/成果：查看左右分区和空状态；切换页签保留同一规范的选择，更换规范清空范围；缺 Agent 或未确认结果时相应操作禁用。
5. 能耗页：曲线与表单内容完整，缺测与零值区分；保存当前样本与整包提交仍为独立操作。
6. 在约 1380px、1024px、390px 宽度检查布局、表格滚动、导航展开、键盘焦点及长项目名。实际写操作请使用专门验收数据。
