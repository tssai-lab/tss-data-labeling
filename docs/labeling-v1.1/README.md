## 必须统一的规则

本阶段新增：[13 已有项目和图片直接标注](13-project-editor-phase-one.md)。根据用户明确的阶段安排，新增不依赖领取的项目入口；10—12保留为原领取模式的接口与历史验证，不作为本阶段必须先领取的要求。

2026-11-07 编辑器本地实现交接补充：[10 编辑器接口](10-editor-integration.md)、[11 交接单](11-editor-handoff.md)、[12 验证记录](12-editor-verification.md)。这些记录说明本地已验证内容与合并前待办，不表示上述设计已全部上线。

1. 统一登录只是共用身份入口。需求方、标注员、标注管理员仅属于数据标注平台，不代表训练平台角色；训练权限保持独立。
2. 所有启用且可使用标注平台的人工用户均可标注，也能自主创建项目成为该项目需求方，无需管理员授权。创建准入未来可调整；当前没有申请/审批页。
3. 首期为人工按包领取与提交。包大小默认10个样本/包、同一样本标注人数默认1，均在发布前可设置；必须实际支持N=2。
4. 一个样本可对应多份个人结果；结果归属领取记录，不在样本上保存唯一共享答案。
5. 首期需求方查看并导出，不默认增加审批返工或分歧裁决。算法、集成和模型调用后置。
6. Label Studio 选型沿用已确认决定；待验证的是具体发行版、版本和任务隔离接入方式，不再把是否使用它反复列作未决问题。
7. 甲方文档和架构图不展示手动Demo；现有Demo运行资源保留，内部部署方案负责隔离，不删除它。
