## 当前业务规则

1. 只上传未标注数据，不导入外部标注；首个完整流程采用图片单标签分类。
2. 统一登录共用身份，需求方/标注员/标注管理员属于标注业务，不复用训练 roleId；启用用户可自主创建项目。
3. 需求方选择人工或 AI：人工自行领取；AI 分配到能力匹配的 Agent。当前不做人机同时编辑。
4. 人工按包领取，包内全部完成后逐包独立提交；AI 直接按选定样本范围批量执行，不要求人工包或人工提交接口。AI 批次结束固定成功候选和失败清单，成功候选可供 owner 审核；两类结果都需需求方最终确认。同一样本不同时交人工和 AI。
5. 需求方核查、调整或确认；可选全部或部分样本再次发布，并固定是否携带已有结果及其版本。
6. 平台推荐未完成和 owner 标记待修正的样本；低置信度不自动变成待修正，不自动再发布。
7. AI 结果先展示给需求方，再由其设置阈值、预览并点击批量确认；中低/未知分数如何处理仍由需求方决定。
8. 先做单人工领取，保留多人独立结果结构；集成模块接受批量输入，先实现分类多数投票，不覆盖原答案、不自动审核。
9. 只裁剪复用 Label Studio 编辑器代码，不部署启动其整体服务。模型也不要求必须使用大模型。
10. 任务最终完成由 owner 明确确认，成果导出固定已确认结果版本，保留历史。
11. 新模块使用独立标注业务库和文件边界，不迁移或覆盖登录、训练与旧演示资源；甲方架构不展示旧手动 Demo。

## 进度说明

当前代码已有身份、项目、图片导入、任务包、领取、分类草稿与提交等基础。新方案要求人工按包完整提交，AI 按需求方选择的样本范围执行；轮次、AI 执行、置信度审核、集成和成果流程仍按 05 推进。编辑器接入以 10 为准，当前设计不要求启动完整 Label Studio 服务。

本文档描述需求与研发设计，不代表所有功能已经实现、迁移、测试或部署。详细实施默认值与待核实的模型、资源情况见 05；历史操作记录不替代当前环境核验。
