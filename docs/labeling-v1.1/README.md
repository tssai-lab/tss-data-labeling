## 使用和维护

新成员先读产品、架构与分工；前后端联调查接口；接入图片、能耗或新任务查插件和编辑器文档；业务方确认能耗规则查领域文档。需要判断“现在做到了哪里”只查 09-status.md，再查看对应证据。

- 业务规则不在团队分工或阶段进度中另写一份；接口字段不在接入指南重复维护。
- 新实现更新对应主题及 09-status.md；带日期的原始测试报告放 archive，明确环境、版本和未验证项。
- 部署和恢复统一引用 [标注服务发布说明](../../labeling-service/RELEASE.md)，不在本目录再维护一套部署操作。
- 文档归档不表示线上停用，也不将历史测试数量自动算成当前版本已通过。
