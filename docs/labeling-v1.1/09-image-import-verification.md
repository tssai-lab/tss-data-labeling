## 独立审查

一次独立只读代码审查提出两项 Important，无 Critical，无待处理 Minor：

1. ZIP64 目录预检查与解压库目录选择可能不一致。新增 `rejectsUnderstatedZip64DirectoryBeforeLibraryAllocation`、`rejectsContradictoryZip32RecordsWhenZip64LocatorExists`；先观察失败，修复为识别实际 ZIP64 locator、检查 ZIP32/ZIP64 一致性和中央目录完整边界，再验证通过。
2. 示例复用创建键可能拿到旧 UPLOADING 快照。实际 HTTP 测试增加完成后的第二次同键调用，先观察 UPLOAD_CLOSED 失败；修复为取得 batchId 后先 GET 最新状态，再验证通过。

最终完整测试与打包在上述修复后重新执行。原 V1/V2 迁移未修改。

- 沿用用户提供的总体设计，在已有 labeling-service 内实现，不另建一套登录或训练后端。

- 使用新克隆的功能分支隔离工作，没有修改用户已有检出或直接修改共享分支。
- 真实数据集尚未选定：兼容性、容量与性能需要之后实测；当前配置是初始值，不是容量承诺。
- 测试调用真实 IdentityClient/ActorService，但外部统一身份服务由测试 HTTP 桩提供。尚未使用训练平台真实 Token 做共同联调。
